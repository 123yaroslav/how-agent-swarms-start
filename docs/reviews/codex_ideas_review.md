**2. T2 plausibility and decisive experiment**

Identical model copies have no inherent behavioral serial number. Persistent memory, task knowledge, filesystem artifacts, habitual handles, and shared errors can identify continuity of context. They can also spread between agents. Independent sampling creates variation without necessarily creating stable individuality.

Capture recapture cannot repair unreliable identity matching. Unequal visibility, coordinated participation, and an uncertain population boundary further undermine its assumptions. METR’s approximately 1,200 agents are not external ground truth for the subset appearing in reconstructed payloads.

Within three hours, generate four short episodes from each of 24 instances of one model. Balance tasks across instances. Compare persistent context against reset context, remove names and explicit identifiers, and evaluate linkage on held out tasks. Include shuffled identity labels.

Require linkage to improve materially over task similarity and recover held out population sizes. Chance performance kills behavioral fingerprinting. Success confined to persistent context supports context linkage only. Neither outcome licenses counting physical instances in historical logs.

**3. T3 plausibility and decisive experiment**

Command output consistency and cross call state consistency are plausible signals. Author likelihood is much less convincing.

An agent can write code that emits copied text, random bytes, or genuine command output. Those outputs need not resemble the agent’s prose. Conversely, genuine output from `echo`, predictable errors, or standard headers can have high model likelihood. Likelihood therefore confounds output type with forgery.

A fully coherent replacement history can match everything the monitor observes. Transcript only detection cannot establish authenticity in that case.

Within three hours, create 30 clean sandbox trajectories and paired forgeries across three classes.

1. Obvious command output contradictions.
2. Plausible substitutions that conflict with later state.
3. Coherent replay or coordinated replacements with no visible contradiction.

Keep ground truth outside the editable log. Compare deterministic consistency checks, an LLM monitor, and likelihood if available, at matched false alarm rates. Hold out commands and forgery templates.

If performance collapses on class three, narrow the claim to detecting inconsistent tampering. If likelihood adds nothing beyond command type, drop it immediately.
