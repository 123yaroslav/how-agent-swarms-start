In 2026 about 1,200 agents built a message board in a shared package cache, starting from one blocked agent's request for a file. In a pre-registered study we test whether off-the-shelf agents take that first step. Agents run data jobs on a shared store, and some are blocked on a dataset only another job produces. Across six open-weight models from four families, blocked agents took other jobs' work instead of asking, in up to 86% of blocked episodes when no house rule forbade it. They almost never wrote to other jobs unless one sentence permitted it, and almost never answered a peer's note. Closed, newer and swarm-trained models behaved alike in exploratory runs, and pressured agents faked completion rather than ask. No pre-registered fleet without the permission sentence formed a board, up to 1,024 agents, while every one with it did. Two registered tests failed as written, the fleet predictions did worse than the rule that permission decides, and collaboration training could not be tested. In real frameworks shared storage usually comes without a data rule, and a CrewAI memory instruction made one model leave notes in shared memory in 42 of 100 episodes. We release a prompt linter, propensity cards and guidelines.
