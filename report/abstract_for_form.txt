In 2026 about 1,200 agents built a message board in a shared package cache, starting from one blocked agent's request for a file. We ask whether today's agents take that first step on their own. In a pre-registered study, agents run data jobs on a shared store, and some jobs cannot finish without a dataset that only another job produces. Across six open-weight models from four families, blocked agents under the plain prompt did not ask other jobs for help. When nothing forbade it, they quietly took other jobs' work instead, in up to 86% of blocked episodes, and one rule in the system prompt nearly stopped this. One sentence permitting notes made most of them ask. Without it they almost never answered another agent's note, even one they had seen. Two closed models, a newer open model and a model trained to run agent swarms behaved the same way in exploratory runs. No pre-registered fleet without permission formed a message board, even at 1,024 agents, while every pre-registered fleet with permission did. Two registered tests failed as written, and we report why. The registered test of collaboration fine-tuning could not be run. The main risk in shared storage today is silent taking. Most framework prompts that give agents shared storage lack the one-line rule against it, and one framework's memory-tool sentence made one of three models leave notes in shared memory. We release a prompt linter, propensity cards and guidelines.
