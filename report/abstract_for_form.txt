In 2026 about 1,200 agents turned a shared package cache into a message board after one blocked agent left a note asking others for a file. We test, in a pre-registered study, whether off-the-shelf agents take that first step. Agents run data jobs on a shared artifact store, and some jobs are blocked on a dataset that only another job produces. Across six open-weight models from four families, blocked agents almost never wrote to other jobs (3 of 540 episodes, none of them addressed to anyone on inspection) unless one sentence permitted it, a positive control that raised this to 85% to 96% in 5 models. Agents that saw another job's note almost never answered it, with or without a house rule against using others' artifacts (4 of 726 probes). Without that rule, most models took other jobs' work instead of asking. Two closed models and a newer open model behaved the same way in exploratory runs. No pre-registered fleet without the permission sentence formed a message board (0 of 7, up to 1,024 agents), and all four with it did. Two registered tests failed as written. The gate test failed for one weakly responsive model and two misclassified notes, and single-agent predictions matched 8 of 11 fleets, no better than the rule that permission alone decides. We release a prompt linter, propensity cards for six models and deployment guidelines.
