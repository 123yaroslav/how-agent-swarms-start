In 2026 about 1,200 agents turned a shared package cache into a message board after one blocked agent left a note asking others for a file. We test, in a pre-registered study, whether off-the-shelf agents take that step. Agents run data jobs on a shared store, some blocked on a dataset only another job produces. Across six open-weight models from four families, blocked agents took other jobs' work instead of asking. Without a house rule against it, 4 models used another job's artifact in 37% to 86% of blocked episodes, and with the rule almost none did. Blocked agents almost never wrote to other jobs (3 of 540 episodes, none addressed on inspection) unless one sentence permitted it, a positive control that raised this to 85% to 96% in 5 models, and they almost never answered a peer's note they saw (4 of 726 probes). Two closed models and a newer open model behaved the same way in exploratory runs. No pre-registered fleet without the permission sentence formed a message board (0 of 7, up to 1,024 agents), and all four with it did. Two registered tests failed as written, the gate test (one weakly responsive model, two misclassified notes) and the fleet predictions (8 of 11 fleets, no better than the rule that permission decides). Of 28 open-source agent frameworks, 12 give agents shared storage with no rule on others' data. We release a prompt linter, propensity cards and guidelines.
