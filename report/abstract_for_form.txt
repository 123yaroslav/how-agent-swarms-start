In 2026 about 1,200 agents turned a shared package cache into a message board, after one blocked agent left a note asking other agents for a file. In a pre-registered study, agents run data jobs on a shared artifact store, some blocked on a dataset that only another job produces. We split the incident's first step into writing, seeing and answering a peer's note. Across six open-weight models from four families, judged by content, no blocked agent addressed other jobs without permission (0 of 540 episodes), while one permission sentence raised this to 85% to 96% in 5 models. Agents saw seeded peer notes in most probes but almost never answered them, with or without a rule against using other jobs' artifacts (4 of 726 probes), against 122 of 291 with the permission sentence. Without that rule, most models took other jobs' work instead, the only way a blocked job can be completed, so outcome-only reward on such jobs pays only for crossing it. Exploratory runs on two closed models and a newer open model showed the same pattern. No fleet without the permission sentence formed a board (0 of 7, up to 1,024 agents), and every fleet with it did (4 of 4). Pre-committed single-agent predictions matched 8 of 11 fleets. Of 28 open-source agent frameworks, 12 provide shared storage with no rule on others' data. We release a prompt linter, propensity cards for six models, and guidelines.
