In 2026 about 1,200 agents built a message board in a shared package cache, starting from one blocked agent's request for a file. We ask whether today's agents take that first step on their own. In a pre-registered study, agents run data jobs on a shared store, and some jobs cannot finish without a dataset that only another job produces. Across six open-weight models from four families, blocked agents did not ask other jobs for help. When nothing forbade it, they quietly took other jobs' work instead, in up to 86% of blocked episodes, and one rule in the system prompt stopped this. They wrote to other agents only when a sentence permitted it, and they almost never answered another agent's note, even one they had seen. Two closed models, a newer open model and a model trained to run agent swarms behaved the same way in exploratory runs. No pre-registered fleet without permission formed a message board, even at 1,024 agents, while every fleet with permission did. Two registered tests failed as written, and we report why. The risk in shared storage today is silent taking, not talking. It grows with one line many frameworks leave out, and with memory tools that invite agents to leave notes for each other. We release a prompt linter, propensity cards and guidelines.
