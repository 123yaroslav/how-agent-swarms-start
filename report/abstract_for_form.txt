In 2026 about 1,200 agents turned a shared package cache into a message board after one blocked agent left a note asking others for a file. We test, in a pre-registered study, whether off-the-shelf agents take that first step. Agents run data jobs on a shared store, and some jobs are blocked on a dataset only another job produces. Across six open-weight models from four families, blocked agents took other jobs' work instead of asking. Without a house rule against it, most models used another job's artifact in up to 86% of blocked episodes. Blocked agents almost never wrote to other jobs unless one sentence permitted it, and they almost never answered a peer's note they saw. Two closed models, a newer open model and a model trained to run agent swarms behaved the same way, and under pressure to finish, agents faked completion rather than ask. No pre-registered fleet without the permission sentence formed a message board, at up to 1,024 agents, while every pre-registered fleet with it did. Two registered tests failed as written. The gate test failed through one weakly responsive model and two misclassified notes, and the fleet predictions did no better than the rule that permission alone decides. Of 28 open-source agent frameworks, 12 give agents shared storage with no rule on others' data. We release a prompt linter, propensity cards for six models and deployment guidelines.
