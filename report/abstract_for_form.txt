In 2026 about 1,200 agents built a message board in a shared package cache, starting from one blocked agent's request for a file. We test in a pre-registered study whether off-the-shelf agents take that step. Agents run data jobs on a shared store, some blocked on a dataset only another job produces. Across six open-weight models from four families, blocked agents took other jobs' work instead of asking. Without a house rule, most models used another job's artifact in up to 86% of blocked episodes. They almost never wrote to other jobs unless one sentence permitted it, and almost never answered a peer's note. In exploratory runs, two closed models, a newer open model and a swarm-trained model behaved alike, and pressured agents faked completion rather than ask. No pre-registered fleet without the permission sentence formed a board, up to 1,024 agents, while every one with it did. Two registered tests failed as written. The gate test failed through one weakly responsive model and two misclassified notes, and the fleet predictions did worse than the rule that permission alone decides. Collaboration training could not be tested. Of 13 open-source agent projects whose prompts give agents shared storage, 12 lack a rule on others' data in some prompt, and a CrewAI memory instruction made one model's blocked agents leave notes in shared memory in 42 of 100 episodes, and two other models rarely. We release a prompt linter, propensity cards and guidelines.
